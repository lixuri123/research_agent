# Multiple model providers

用户已批准：多个 OpenAI 兼容 Provider；每个 Provider 独立名称、地址、密钥、模型列表及默认模型。支持新增、编辑、删除；输入框旁按服务/模型选择。保留旧单 Provider 配置和密钥不回显行为。

配置文件升级为版本 2 的注册表，保留不可变配置版本。任务提交保存 provider_id、model、revision，不含密钥；Worker 在任务作用域恢复该版本。子 Agent 通过现有 copy_context 继承，研究图节点通过 LangGraph 的上下文传播读取同一配置。明确选中的模型供整个任务使用；旧调用方不选时保留角色模型规则。服务删除从选择列表移除，已有任务引用的历史版本保留。

Provider 编辑管理面板保持现有视觉风格，模型列表逐行输入，默认和角色模型从列表选择。聊天选择器按服务分组，保存后刷新列表。选择无效时后端拒绝；列表无法加载时禁止提交，以免静默切换服务。

保存原子替换并在同进程锁内读取合并；版本 1 首次编辑或提交任务时迁移；首次没有文件时由环境配置生成默认服务。连接测试使用表单和指定服务的已有密钥，不保存，不复用其他服务密钥。

离线测试覆盖迁移、独立密钥、新增编辑删除/default、任务固定与跨进程恢复、子任务上下文、校验脱敏和现有兼容接口；浏览器覆盖两服务选择与提交请求，前端构建验证。
