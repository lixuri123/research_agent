# 结构化人物描述验收记录

## 交付

- 新增独立 `profile/` 包及 `/profile` 管理接口，开放属性名称、路径和 JSON 内容。
- 固定来源、依据、范围、确认状态、时间和版本元数据；属性与历史同事务提交。
- 修改需要当前版本，防止旧页面覆盖其他修改；删除同时移除当前属性及其历史。
- 工作台“关于我”支持分层查看、新增、修正、确认、失效、删除及历史，桌面与手机均可操作。
- 人物描述不接入现有 Agent 提示词、工具目录或长期记忆召回。本次没有自动从对话提炼属性。

## 验证

- 首次人物属性测试：11 项因功能尚未存在而失败。
- 最终人物属性测试：12 passed，覆盖持久化、开放值、生命周期、来源状态、owner 隔离、并发版本冲突、API 校验及原始内容保留。
- 最终全量测试：202 passed，1 skipped。
- TypeScript 与 Vite 生产构建通过。
- 浏览器在独立临时数据库上操作真实接口，验证文本、数字、嵌套列表/对象的新增；确认、修改、历史、失效、删除、重新打开均通过。
- 1280×900 和 390×844 两种视口均无横向溢出，无浏览器运行错误，截图已检查。
- 浏览器检查使用本地静态服务与临时数据库，不调用模型或使用现有用户人物数据。
- 浏览器检查发现并修正表单标签包含说明文字的问题；最终全部表单控件有明确可识别名称。
- 独立代码检查发现 JSON 文本被全局去除空白、含 `/` 的路径名称在编辑时被拆分两项问题；均已复现并修正。现在保留 JSON 文本原始空白，编辑器逐层填写并保留路径边界。
- 新增持久化回归先失败后通过；浏览器回归覆盖含 `/` 的名称与带空格对象文本的编辑保存。独立复查未发现剩余实质问题。

截图位于 `.tmp/profile-desktop.png`、`.tmp/profile-mobile.png`，浏览器检查脚本为 `.tmp/check_profile_ui.py`。

## 使用

重新启动 API（可 Ctrl+C 停止原 `start.bat` 后再次启动）并刷新工作台，点击侧栏“关于我”。来源引用由调用者提供，当前不自动验证对应消息或材料存在；接口继续沿用本地单用户入口。
