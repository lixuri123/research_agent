# 动态协作审核记录

独立审核发现并修复：

1. 研究模式未传播父工具白名单，可能调用未授权的本地 PDF/知识库工具。现在 run_tool 使用任务上下文白名单，研究子流程显式传入父目录的只读子集。回归测试阻止本地 PDF 访问。
2. queued 到 running 转换与取消存在竞态。现在持锁重新检查取消再转换。回归测试控制两个检查点之间的取消时机。
3. 研究阅读循环和模型重试只在节点边界检查取消。现在 Budget.check 运行当前子任务执行检查，实际模型和工具边界都传播取消，取消异常继承 BudgetExceeded，避免被 Reader 的普通异常降级吞掉。回归测试在第一次实际阅读模型请求中取消，后续片段不再请求。
4. 子任务仍继承父 MCP 写入授权，恢复后的旧 safe 目录可能与当前 sensitive 配置冲突。现在子任务清空 cap.authorized，实际 MCP 权限仍由当前客户端检查。回归测试验证不会将父写入授权交给子任务。
5. 完成后的进度事件失败可能覆盖已经保存的成果。现在把进度事件作为派生观测记录，失效租约仍立即停止，单独的事件失败保留权威阶段状态。回归测试覆盖 spawned/progress/finished 事件失败及重启后结果保留。

共享预算的并发预留/结算审核通过。主 Agent 的完成检查、子任务稳定 ID、终态复用、最新进度输入和来源元数据摘录通过复审；大内容摘录标注 truncated。

全量回归发现三处已有测试夹具过时：缓存仓储替身缺少 record_event、Skill 路由使用的记忆管理器未替换、启动测试未包含后来增加的文件变更和执行服务。只修正测试夹具，未改变这些生产服务。
