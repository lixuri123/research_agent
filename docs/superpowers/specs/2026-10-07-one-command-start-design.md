# 一条命令启动本地工作台

用户要求避免每次分别启动 API 和 Worker。采用根目录 `start.bat` 调用现有 `.venv` Python 的监督脚本 `scripts/start.py`，保留服务入口与独立进程架构。

脚本定位项目根目录，检查 `.env` 与前端构建，拒绝占用或不可用端口；启动 API 并通过本地 health 检查确认就绪后启动 Worker。两个服务输出到同一终端，Ctrl+C 关闭本次启动的进程；任一服务退出时停止其余服务。清理某个进程失败时仍继续清理其他进程。

默认仅监听 127.0.0.1:8000，可通过 `--port` 指定端口。不修改环境文件、不安装依赖、不自动执行构建、不复用已有服务。

验证包括 API 启动失败不启动 Worker、Worker 退出关闭 API、启动期间 Ctrl+C 清理 API，以及真实独立 Python 子进程退出时回收同伴。完整项目测试验证没有影响其他入口。
