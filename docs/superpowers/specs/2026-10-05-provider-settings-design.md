# OpenAI 兼容 Provider 设置

用户已批准实现：当前仅支持 OpenAI 兼容协议，不接入 Anthropic 原生协议。

侧栏增加 Provider 设置入口。配置 API 地址、密钥、默认模型和可选角色模型；支持保存与测试连接。密钥输入留空保留现有密钥，读取接口只返回是否已配置。测试使用当前表单，不自动保存，发送一次最小模型请求，错误消息不包含远端正文或密钥。

运行配置写入 data/provider.json，原子替换，不覆盖 .env；该文件加入忽略列表。API 和 Worker 必须使用相同路径。get_settings 每次读取覆盖配置，新建模型客户端使用更新后的参数，已经创建的客户端继续使用旧参数。文件损坏时明确失败，不静默回退。现有环境配置作为默认值。

离线验证：保存/加载、密钥保留、输入验证、跨进程读取、错误脱敏、测试连接不保存，以及现有模型网关回归；构建前端。真实 Provider 连通性由用户在设置页测试。
